🏗️ Project: Local Arch-Copilot (NiceGUI Edition)
1. 시스템 개요 (System Overview)
Core Engine: Python ast (0.1초 구조 분석).

AI Engine: GPT-OSS-20B (MoE 아키텍처, 4-bit Quantized via Ollama).

User Interface: NiceGUI (비동기 이벤트 기반, NO Rerun).

Target: 사용자님의 로컬 PC (RTX 5070 Ti)에서 독립 실행.

3. 단계별 상세 개발 로드맵
Phase 1: 환경 설정 및 코어 엔진 (Base Setup)
목표: UI 없이 터미널에서 프로젝트 구조를 0.1초 만에 추출하고 JSON으로 저장한다.

가상환경 및 라이브러리 설치:

Bash

pip install nicegui networkx ollama
scanner.py 구현 (AST):

ast.parse()를 사용하여 파일별 Import, Class, Function 시그니처 추출.

최적화: 파일 내용을 전부 읽지 않고, 메타데이터만 추출하여 메모리 사용량 최소화.

graph.py 구현:

networkx.DiGraph를 사용해 의존성 방향 그래프 생성.

NiceGUI의 Mermaid 컴포넌트가 읽을 수 있는 문자열 포맷으로 변환하는 기능 추가.

Phase 2: NiceGUI 레이아웃 및 대시보드 (UI Skeleton)
목표: 웹 브라우저가 아닌 '앱'처럼 보이는 빠릿한 인터페이스 구축.

main.py & layout.py:

Native Mode: ui.run(native=True) 설정을 통해 크롬 창이 아닌 독립된 앱 창으로 실행.

Dark Mode: 개발자 친화적인 다크 모드 기본 적용.

Async Handler: 버튼 클릭 시 화면이 멈추지 않도록 async def로 이벤트 핸들러 작성.

File Picker:

사용자가 분석할 프로젝트 폴더(D:\Stock\work_plan)를 선택하는 기능.

NiceGUI의 ui.upload 대신 로컬 경로를 직접 입력받거나 탐색기 연동.

Phase 3: 시각화 및 정적 분석 (Visualization)
목표: AI 없이도 확인 가능한 정보(그래프, 순환 참조)를 시각적으로 보여준다.

visualizer.py (Mermaid 연동):

Scanner가 만든 데이터를 기반으로 의존성 그래프를 그립니다.

NiceGUI 장점 활용: 그래프의 노드(파일)를 클릭하면, 해당 파일의 상세 정보(함수 목록 등)가 팝업으로 뜨도록 이벤트 바인딩 (Streamlit에선 매우 어려운 기능).

Rule-based Check:

순환 참조(Cycle)가 발견되면 빨간색 경고 배지 표시.

layer_violation (예: Domain이 Infra 참조)을 정규식으로 1차 필터링하여 리스트업.

Phase 4: GPT-OSS-20B 두뇌 이식 (AI Integration)
목표: 5070 Ti의 연산력을 사용하여 심층 분석 및 리팩토링 제안.

client.py (Ollama Wrapper):

비동기(AsyncClient)로 Ollama API 호출 (UI 블로킹 방지).

GPT-OSS-20B 모델 지정.

prompts.py (MoE 최적화):

JSON으로 압축된 구조 데이터를 입력으로 받도록 프롬프트 설계.

System Prompt: "You are a Clean Architecture Auditor. Analyze the provided JSON dependency map."

chat.py (Interactive Report):

Streaming Response: AI가 답변하는 도중에 글자가 타자기처럼 찍히도록 ui.chat_message 활용.

Action Button: AI의 답변 아래에 [코드 수정 제안 보기] 버튼을 생성하여, 클릭 시 수정된 코드를 팝업으로 띄움.

4. 핵심 코드 예시 (NiceGUI 구현)
가장 중요한 **"비동기 처리(속도)"**와 **"UI 구조"**를 보여주는 main.py와 visualizer.py의 프로토타입입니다.

Python

# main.py
from nicegui import ui
import asyncio
from app.core.scanner import scan_project_structure
from app.ui import visualizer, chat

# 전역 상태 (분석된 데이터)
app_state = {"path": "", "data": None}

@ui.page('/')
def main_page():
    # 1. 헤더 (Header)
    with ui.header().classes('bg-slate-900 text-white'):
        ui.label('Local Arch-Copilot').classes('text-xl font-bold')

    # 2. 사이드바 (Sidebar - 설정 및 실행)
    with ui.left_drawer(value=True).classes('bg-slate-800 text-white'):
        ui.label('Project Path')
        path_input = ui.input(placeholder='D:/Stock/work_plan').classes('w-full')
        
        # [핵심] 비동기 함수 바인딩 (화면 멈춤 없음)
        async def run_scan():
            app_state["path"] = path_input.value
            ui.notify(f'Scanning: {app_state["path"]}...')
            
            # CPU 바운드 작업(스캔)은 별도 스레드/프로세스로 분리 가능하지만
            # AST는 워낙 빨라 그냥 실행해도 무방
            app_state["data"] = scan_project_structure(app_state["path"])
            
            ui.notify(f'Scan Complete! Files: {len(app_state["data"])}')
            visualizer.update_graph(app_state["data"]) # 그래프 갱신

        ui.button('Analyze Structure', on_click=run_scan).classes('w-full bg-blue-600 mt-4')

    # 3. 메인 콘텐츠 (Tabs)
    with ui.tabs().classes('w-full') as tabs:
        tab_graph = ui.tab('Graph')
        tab_chat = ui.tab('AI Analysis')

    with ui.tab_panels(tabs, value=tab_graph).classes('w-full h-full'):
        # 그래프 탭
        with ui.tab_panel(tab_graph):
            visualizer.create()
            
        # AI 채팅 탭
        with ui.tab_panel(tab_chat):
            chat.create(app_state)

ui.run(
    title='Arch-Copilot',
    dark=True,
    native=True,  # 데스크탑 앱 모드
    window_size=(1200, 800)
)

# app/ui/visualizer.py
from nicegui import ui

graph_container = None

def create():
    global graph_container
    # Mermaid 그래프가 들어갈 빈 공간 생성
    graph_container = ui.element('div').classes('w-full h-full border border-gray-700 p-4')
    ui.label('Please run analysis first.').bind_visibility_from(graph_container, 'visible', backward=lambda x: False)

def update_graph(data):
    # Scanner 데이터를 Mermaid 문법으로 변환
    mermaid_code = "graph TD;\n"
    for file in data:
        safe_name = file['name'].replace('.', '_').replace('/', '_')
        for imp in file['imports']:
            safe_imp = imp.replace('.', '_')
            mermaid_code += f"    {safe_name} --> {safe_imp};\n"
    
    # UI 업데이트 (깜빡임 없이 내용만 교체)
    graph_container.clear()
    with graph_container:
        ui.mermaid(mermaid_code).classes('w-full h-full bg-slate-800 p-4 rounded')
5. 성공을 위한 체크포인트
NiceGUI의 native=True:

이 옵션을 켜면 브라우저 주소창 등이 사라지고 Electron 앱처럼 깔끔한 창으로 실행됩니다. 사용자 경험(UX)이 훨씬 좋아집니다.

GPT-OSS-20B의 Temperature 설정:

아키텍처 분석은 창의성보다 정확성이 중요하므로 temperature=0.1 정도로 낮게 설정하여 Ollama를 호출해야 합니다.

AST 예외 처리:

프로젝트 내에 파이썬 문법 오류가 있는 파일이 있어도 스캐너가 멈추지 않고 try-except로 건너뛰도록 scanner.py를 견고하게 짜야 합니다.
